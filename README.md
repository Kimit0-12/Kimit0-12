# Hey, I'm Kimit0 👋

I like making games, useful apps, and the occasional slightly overcomplicated idea just to see if I can get it working. I learn best by building something real, breaking it, and figuring out why.

Right now, most of my attention is going into **NHub**. It started as a focus app I wanted for myself and slowly grew into its own little world: tasks, focus sessions, flexible breaks, Canutimonedas, unlockable rewards, and **Canutín**, the mascot holding the whole thing together.

On the game side, I work with **Unity, Godot, and C#**. I also use **Python, HTML/CSS, Maya, Blender, and Photoshop**, depending on what the project needs. I'm especially interested in QA, game systems, and level design — the bit where an idea stops being a document and becomes something you can actually play.

This profile is still very new, so I'll add projects as they're ready instead of filling it with placeholders.

Next goal: release a small game that is actually finished, not permanently “almost there”.
