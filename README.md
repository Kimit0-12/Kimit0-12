## How I work

- Build something real, test it, break it and understand why.
- Keep the experience playful without losing clarity.
- Treat QA and polish as part of the design, not the final chore.
- Finish and ship — even when the next idea is already knocking.

> **Current quest:** grow NHub, keep improving SLU Pocket and release a small game that is genuinely finished.
